📚 Conceito de Pilhas (LIFO)

  • Pilha = estrutura onde o último que entra é o primeiro que sai
  • 📖 Regra: LIFO – Last In, First Out
  • 🥞 Exemplo físico: pilha de pratos, livros
Topo → C
B
A

🔄 CRUD com Pilha (nosso projeto)

  • Create → Push (empilhar novo aluno)
  • Read → Peek (ver topo) / Percorrer toda pilha
  • Update → Só é possível após Pop (remove e insere modificado)
  • Delete → Pop (remove do topo)
⚠️ Limitação da pilha
Não permite acesso ao meio
Update exige desempilhar/reempilhar
